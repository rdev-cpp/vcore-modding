# Справочник API

Среда исполнения Velvetics-Core предоставляет разработчикам богатый набор высокоуровневых интерфейсов для взаимодействия с игровым миром, графикой, физикой и вводом.

---

## Архитектура глобальных таблиц

Все подсистемы движка сгруппированы по глобальным таблицам. Для максимального удобства авторов скриптов все таблицы и методы продублированы в двух стилях: **PascalCase** и **snake_case**:

| Глобальная таблица | Альтернативное имя | Назначение |
| :--- | :--- | :--- |
| [`Mod`](mod.md) | `mod` | Метаданные текущего мода, пути, загрузка текстур, спрайтов и текста |
| [`World`](world.md) | `world` | Спавн пропов, оружия, ящиков, поиск и уничтожение игровых объектов |
| [`Camera`](camera.md) | `camera` | Управление ортографическим зумом, позицией камеры и координатами |
| [`Input`](input.md) | `input` | Опрос клавиш, кнопок мыши, колесика прокрутки и экранных координат |
| [`Physics`](physics.md) | `physics` | 2D рейкастинг (Raycast) и управление вектором гравитации мира |
| [`Events`](events.md) | `events` | Глобальная шина событий для синхронизации и межмодового общения |
| [`Dials`](dials.md) | `dials` | Чтение системных настроек (язык, громкость, итерации физики, gore) |
| [`Time`](time_log.md) | `time` | Дельты времени, шкала времени (slow-motion / пауза) |
| [`Log`](time_log.md) | `log` | Вывод сообщений, предупреждений и ошибок в лог с префиксом мода |

---

## Зарегистрированные типы данных Unity (UserData)

Интерпретатор MoonSharp сконфигурирован с автоматической поддержкой стандартных типов Unity, что позволяет безопасно оперировать ими внутри Lua-скрипта:

- **Структуры:** `Vector2`, `Vector3`, `Color`
- **Игровые объекты и компоненты:** `GameObject`, `Transform`, `Component`
- **Физика 2D:** `Rigidbody2D`, `Collider2D`, `BoxCollider2D`
- **Графика и рендеринг:** `SpriteRenderer`, `Sprite`, `Texture2D`
- **Системы камеры:** `Camera`, `RoamCam`
