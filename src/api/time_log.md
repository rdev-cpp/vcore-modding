# Модули Time и Log (Время и логи)

В этом разделе описаны методы управления игровым временем и система безопасного логирования.

---

## Модуль Time (Время)

Таблица `Time` (или `time`) управляет масштабом времени и предоставляет доступ к таймингам Unity.

### Справочник методов

| Метод | Псевдоним | Возвращает | Описание |
| :--- | :--- | :--- | :--- |
| `Time.get_delta_time()` | `Time.GetDeltaTime()` | `number` | Интервал времени в секундах между предыдущим и текущим кадром рендера |
| `Time.get_fixed_delta_time()`| `Time.GetFixedDeltaTime()` | `number` | Интервал фиксированного физического шага симуляции |
| `Time.get_unscaled_delta_time()`| `Time.GetUnscaledDeltaTime()` | `number` | Дельта времени реального мира, независящая от замедления времени |
| `Time.get_time()` | `Time.GetTime()` | `number` | Общее игровое время с момента запуска сцены |
| `Time.get_unscaled_time()` | `Time.GetUnscaledTime()` | `number` | Реальное время в секундах с момента запуска |
| `Time.get_time_scale()` | `Time.GetTimeScale()` | `number` | Текущий масштаб времени (`1.0` = нормальная скорость) |
| `Time.set_time_scale(scale)` | `Time.SetTimeScale(scale)` | `void` | Устанавливает масштаб времени (значение не может быть меньше `0.0`) |

### Пример реализации слоу-мо (Slow Motion):
```lua
local slowmo_active = false

function OnUpdate(dt)
    -- Переключение слоу-мо по клавише T
    if Input.get_key_down("T") then
        slowmo_active = not slowmo_active
        if slowmo_active then
            Time.set_time_scale(0.2) -- Замедление в 5 раз
            Log("Режим замедления времени ВКЛЮЧЕН (0.2x)")
        else
            Time.set_time_scale(1.0) -- Возврат нормальной скорости
            Log("Нормальная скорость времени восстановлена")
        end
    end
end
```

## Функции логирования (Log)

Среда исполнения автоматически подставляет имя мода в квадратных скобках к каждому выводимому сообщению.

### `Log(message)` / `log(message)`
Выводит информационное сообщение в консоль Unity и файл лога.
```lua
Log("Объект успешно создан")
-- Вывод в консоль: [MyMod] Объект успешно создан
```

### `LogWarning(message)` / `log_warning(message)`
Выводит предупреждение желтым цветом в консоли.
```lua
LogWarning("Текстура не найдена, используется заглушка")
```

### `LogError(message)` / `log_error(message)`
Выводит сообщение об ошибке красным цветом.
```lua
LogError("Не удалось распарсить конфигурационный файл")
```

### Стандартный `print(...)`
Стандартная функция Lua `print` также перенаправлена в системный лог с префиксом мода.
