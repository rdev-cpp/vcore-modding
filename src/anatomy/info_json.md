# Манифест info.json

Файл `info.json` располагается в корневой папке мода и описывает его метаданные для системы управления модами (`ModManager`) и встроенного Воркшопа.

---

## Спецификация схемы

```json
{
  "id": "cool_swords",
  "version": "1.2.0",
  "name": "Cool Swords Pack",
  "author": "Velvetic & rdev",
  "description": "Набор из 5 клинков с настраиваемыми физическими свойствами и спрайтами",
  "dependencies": []
}
```

### Описание полей

| Поле | Тип | Обязательное | Описание |
| :--- | :--- | :--- | :--- |
| `id` | `string` | Да | Уникальный идентификатор мода. Используется для сохранения состояния активации (`vc.mod.<id>`) и связывания зависимостей. Рекомендуется использовать формат `snake_case` или обратный доменный вид (`author.modname`). |
| `version` | `string` | Да | Версия модификации в формате [Semantic Versioning](https://semver.org) (`MAJOR.MINOR.PATCH`). Значение по умолчанию: `"1.0.0"`. |
| `name` | `string` | Да | Человекочитаемое название мода, отображаемое в игровом списке и карточках Воркшопа. |
| `author` | `string` | Нет | Имя автора или команды разработчиков. |
| `description`| `string` | Нет | Описание возможностей, горячих клавиш и предназначения мода. |
| `dependencies`| `string[]` | Нет | Массив строковых `id` других модификаций, которые должны быть установлены для работы данного мода. |

---

## Правила автокоррекции и отказоустойчивости

Движок `ModManager` содержит встроенные механизмы безопасного восстановления при неполных метаданных:

1. **Отсутствие поля `id`:** Если поле `id` пустое или отсутствует, движок автоматически присваивает моду имя папки, в которой он находится.
2. **Отсутствие поля `name`:** Если имя не указано, в качестве имени используется значение поля `id`.
3. **Отсутствие поля `dependencies`:** Автоматически инициализируется пустым массивом `[]`.
4. **Ошибки синтаксиса JSON:** Если файл поврежден (невалидный JSON), мод переходит в статус ошибки `errorMessage = "Failed to deserialize info.json"` и исключается из выполнения без сбоя всей игры.
