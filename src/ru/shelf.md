# Интеграция в SpawnShelf (Q-меню)

**SpawnShelf** — это системная выдвижная панель спавна предметов, вызываемая в игре нажатием и удержанием клавиши **`Q`**. Панель разделена на 6 тематических полок (дорожек).

Моды могут бесшовно добавлять свои собственные предметы на любую из этих полок.

---

## Таблица полок (Lanes)

| Индекс | Иконка / Категория | Назначение | Примеры предметов |
| :---: | :--- | :--- | :--- |
| **`0`** | **Props (Пропы)** | Ящики, бочки, кирпичи, строительные блоки | Стальной ящик, деревянная бочка |
| **`1`** | **Ragdolls (Куклы)** | Живые персонажи, манекены, ragdoll-тела | Человечек, тренировочный манекен |
| **`2`** | **Guns (Огнестрел)** | Пистолеты, автоматы, дробовики, пушки | Пистолет, револьвер |
| **`3`** | **Melee (Холодное)** | Мечи, топоры, ножи, копья | Меч, булава |
| **`4`** | **Explosives (Взрывчатка)** | Бомбы, динамит, контактные мины | Бочка с горючим, C4 |
| **`5`** | **Misc (Разное)** | Механизмы, колеса, магниты, инструменты | Двигатели, шарниры, лампы |

---

## Синтаксис регистрации

Регистрация производится с помощью функции:

```lua
World.register_spawn_item(lane_index, icon_sprite, spawn_function)
```

- `lane_index` (`number`): число от `0` до `5`.
- `icon_sprite` (`Sprite`): спрайт квадратной иконки для ячейки в панели. Рекомендуемое разрешение: **32x32** или **48x48** пикселей.
- `spawn_function` (`function(x, y)`): функция, принимающая мировые координаты курсора при клике и возвращающая созданный `GameObject`.

---

## Полный рабочий пример

Ниже приведен пример регистрации стального ящика и деревянной бочки на полку `0` (`Props`):

```lua
function OnInit()
    -- 1. Загрузка иконок для интерфейса
    local crate_icon = Mod.load_sprite("icons/steel_crate_icon.png")
    local barrel_icon = Mod.load_sprite("icons/wood_barrel_icon.png")

    -- 2. Регистрация стального ящика на полке 0 (Props)
    World.register_spawn_item(0, crate_icon, function(x, y)
        local spr = Mod.load_sprite("textures/steel_crate.png", 20.0)
        return World.create_prop(
            "SteelCrate",
            spr,
            x, y,
            12.0,  -- Масса: 12 кг
            0.6,   -- Трение
            0.05,  -- Упругость
            1.0    -- Масштаб
        )
    end)

    -- 3. Регистрация бочки на полке 0 (Props)
    World.register_spawn_item(0, barrel_icon, function(x, y)
        local spr = Mod.load_sprite("textures/wood_barrel.png", 20.0)
        return World.create_prop(
            "WoodBarrel",
            spr,
            x, y,
            4.0,   -- Масса: 4 кг
            0.4,   -- Трение
            0.3,   -- Упругость
            1.0    -- Масштаб
        )
    end)

    Log("Предметы успешно добавлены в SpawnShelf!")
end
```

## Особенности взаимодействия в игре

1. Игрок зажимает клавишу **`Q`**, выбирает нужную полку кликом или наведением.
2. При клике по иконке мода включается режим размещения: за курсором мыши отображается полупрозрачный силуэт предмета (Ghost Preview).
3. При клике левой кнопкой мыши в игровом поле вызывается ваша функция `spawn_function(x, y)`, мгновенно порождающая физический объект в заданной точке.
