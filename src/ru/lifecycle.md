# Жизненный цикл мода

Каждый активный мод получает вызовы специальных функций обратного вызова (хуков), соответствующих ключевым фазам жизненного цикла игрового движка.

Движок поддерживает оба стиля именования функций: **PascalCase** (например, `OnInit`) и **snake_case** (например, `on_init`).

---

## Сводная таблица хуков

| Хук (PascalCase) | Хук (snake_case) | Аргументы | Описание |
| :--- | :--- | :--- | :--- |
| `OnInit()` | `on_init()` | `—` | Вызывается один раз сразу после успешной компиляции скрипта. Идеально для регистрации предметов в Q-меню, настройки конфигурации и подписки на события. |
| `OnUpdate(dt)` | `on_update(dt)` | `dt` (`number`) | Вызывается каждый кадр рендеринга. `dt` — дельта времени в секундах (`Time.deltaTime`). Используется для опроса клавиатуры и мыши, управления интерфейсом и визуалом. |
| `OnFixedUpdate(dt)` | `on_fixed_update(dt)` | `dt` (`number`) | Вызывается с фиксированным шагом физики. `dt` — `Time.fixedDeltaTime`. Используется для применения физических сил, расчета импульсов и симуляций. |
| `OnSceneLoaded(index, name)` | `on_scene_loaded(index, name)` | `index` (`number`), `name` (`string`) | Вызывается при каждой загрузке новой сцены. Передает индекс сцены и ее имя. |
| `OnGUI()` | `on_gui()` | `—` | Вызывается во время фазы IMGUI. Используется для отладочного вывода текста и оверлеев. |
| `OnUnload()` | `on_unload()` | `—` | Вызывается перед отключением мода или его перезагрузкой. Предназначен для сброса пользовательских таймеров, очистки состояния и отписки от внешних систем. |

---

## Пример использования всех хуков

```lua
local frame_count = 0

function OnInit()
    Log("Мод активирован. Инициализация ресурсов...")
end

function OnUpdate(dt)
    frame_count = frame_count + 1
    if Input.get_key_down("Space") then
        Log("Пробел нажат на кадре: " .. frame_count .. " (dt: " .. dt .. ")")
    end
end

function OnFixedUpdate(dt)
    -- Физический тик
end

function OnSceneLoaded(scene_index, scene_name)
    Log("Загружена сцена #" .. scene_index .. " ('" .. scene_name .. "')")
end

function OnGUI()
    -- Отрисовка отладочных данных при необходимости
end

function OnUnload()
    Log("Мод выгружается. Освобождение ресурсов завершено.")
end
```

## Обработка ошибок и отказоустойчивость

Если внутри пользовательской функции возникает ошибка (например, попытка вызвать `nil` или деление на ноль):
1. Исключение перехватывается интерпретатором.
2. В консоль выводится информативное сообщение об ошибке с точным указанием номера строки и имени файла:
   ```text
   [CustomProps] Script runtime error: main.lua:24: attempt to perform arithmetic on a nil value
   ```
3. **Игра не вылетает и не зависает:** выполнение остальных систем и других активных модов продолжается в штатном режиме.
