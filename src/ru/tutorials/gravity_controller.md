# Руководство: Управление гравитацией (GravityController)

В этом практическом руководстве мы создадим геймплейную утилиту **"GravityController"**, позволяющую изменять гравитацию в реальном времени с помощью горячих клавиш.

---

## 1. Структура файлов

```text
Mods/GravityController/
├── info.json
└── main.lua
```

---

## 3. Скрипт `main.lua`

```lua
function OnInit()
    Log("GravityController активирован: [G] Невесомость, [H] Инверсия, [J] Норма")
end

function OnUpdate(dt)
    -- Клавиша G: включение невесомости (Zero-G)
    if Input.get_key_down("G") then
        Physics.set_gravity(0, 0)
        Log("Режим невесомости активирован (Zero-G)")
    end

    -- Клавиша H: инверсия гравитации (полет вверх)
    if Input.get_key_down("H") then
        Physics.set_gravity(0, 9.81)
        Log("Инверсия гравитации активирована (вектор вверх)")
    end

    -- Клавиша J: восстановление нормальной гравитации
    if Input.get_key_down("J") then
        Physics.set_gravity(0, -9.81)
        Log("Нормальная гравитация восстановлена")
    end
end

function OnUnload()
    -- Безопасный возврат к стандартной физике при выгрузке мода
    Physics.set_gravity(0, -9.81)
    Log("GravityController выгружен: физика сброшена")
end
```

---

## 4. Разбор ключевых моментов

1. **`Input.get_key_down("G")`:**  
   Срабатывает строго в кадр нажатия клавиши, предотвращая повторные вызовы.
2. **`Physics.set_gravity(x, y)`:**  
   Мгновенно обновляет глобальный вектор гравитации для всех физических тел в сцене (ящиков, рэгдоллов, оружия).
3. **Безопасная выгрузка (`OnUnload`):**  
   Если игрок отключает мод через меню, гравитация автоматически возвращается к стандартному значению `(0, -9.81)`.
