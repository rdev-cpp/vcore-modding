# Модуль Dials (Настройки игры)

Таблица `Dials` (или `dials`) предоставляет доступ только для чтения к глобальным параметрам конфигурации игры VCore (`CoreDials`).

---

## Справочник методов

### `Dials.get_language()`
Возвращает текущий выбранный язык интерфейса.

- **Возвращает:** `number`:
  - `0` — Русский язык (`RU`)
  - `1` — Английский язык (`EN`)
- **Псевдоним:** `Dials.GetLanguage()`.

---

### `Dials.get_gore()`
Возвращает текущий уровень отображения жестокости и крови.

- **Возвращает:** `number` (`0` — отключено / цензура, `1` — включено).
- **Псевдоним:** `Dials.GetGore()`.

---

### `Dials.get_iterations()`
Возвращает количество итераций физического солвера за один шаг симуляции (`PhysSteps`). Используется для адаптации тяжести расчетных алгоритмов под текущую производительность игрока.

- **Возвращает:** `number` (например: 6, 8, 12, 16).
- **Псевдоним:** `Dials.GetIterations()`.

---

### `Dials.get_graphics()`
Возвращает индекс текущего графического пресета.

- **Возвращает:** `number`.
- **Псевдоним:** `Dials.GetGraphics()`.

---

### `Dials.get_music_volume()` / `Dials.get_sfx_volume()`
Возвращает текущую громкость музыки и звуковых эффектов в диапазоне от `0.0` до `1.0`.

- **Псевдонимы:** `Dials.GetMusicVolume()`, `Dials.GetSfxVolume()`.

---

## Пример адаптации мода под настройки

```lua
function GetLocalizedTitle()
    local lang = Dials.get_language()
    if lang == 0 then
        return "Тяжелый блок"
    else
        return "Heavy Block"
    end
end
```
