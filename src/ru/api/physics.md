# Модуль Physics (Физика и лучи)

Таблица `Physics` (или `physics`) позволяет взаимодействовать с двумерным физическим движком Box2D в Unity: испускать лучи (Raycast) и управлять глобальным вектором гравитации.

---

## 2D Рейкастинг (Raycast)

### `Physics.raycast(originX, originY, dirX, dirY, distance)`
Выпускает физический луч из точки `(originX, originY)` в направлении вектора `(dirX, dirY)` на максимальное расстояние `distance`.

- **Параметры:**
  - `originX`, `originY` (`number`): начальная точка луча.
  - `dirX`, `dirY` (`number`): вектор направления (рекомендуется нормализовать).
  - `distance` (`number`): максимальная дистанция проверки.
- **Возвращает:** таблицу результатов пересечения или `nil`, если луч ни с чем не столкнулся.
- **Псевдоним:** `Physics.Raycast(...)`.

### Структура таблицы попадания:
```lua
{
    point_x = 12.4,        -- Мировая координата X точки удара
    point_y = -3.2,        -- Мировая координата Y точки удара
    normal_x = 0.0,        -- Вектор нормали поверхности X
    normal_y = 1.0,        -- Вектор нормали поверхности Y
    distance = 4.82,       -- Расстояние от старта луча до препятствия
    game_object = obj      -- Задетый игровой объект (GameObject)
}
```

```lua
-- Пример: проверка, есть ли под курсором объект
local mouse = Input.get_mouse_position()
local world_pos = Camera.screen_to_world(mouse.x, mouse.y)

-- Пускаем короткий луч вниз
local hit = Physics.raycast(world_pos.x, world_pos.y, 0, -1, 10.0)
if hit then
    Log("Луч задел объект на расстоянии: " .. hit.distance .. " м")
end
```

## Управление гравитацией

### `Physics.get_gravity()`
Возвращает текущий глобальный вектор ускорения свободного падения.

- **Возвращает:** таблицу `{ x = number, y = number }` (стандартное значение в игре: `{ x = 0, y = -9.81 }`).
- **Псевдоним:** `Physics.GetGravity()`.

---

### `Physics.set_gravity(x, y)`
Устанавливает новый вектор гравитации в реальном времени.

- **Параметры:** `x`, `y` (`number`).
- **Псевдоним:** `Physics.SetGravity(...)`.

```lua
-- Включение режима невесомости (Zero-G)
Physics.set_gravity(0, 0)

-- Инверсия гравитации (полет вверх)
Physics.set_gravity(0, 9.81)

-- Восстановление стандартной физики
Physics.set_gravity(0, -9.81)
```
