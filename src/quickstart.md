# Быстрый старт

В этом руководстве мы создадим рабочий мод **"BoxSpawner"** с нуля за 3 минуты. Мод будет выводить приветственное сообщение при старте и спавнить ящик в точке курсора при нажатии клавиши `H`.

---

## Шаг 1. Создание папки мода

Перейдите в корневую директорию игры и откройте папку `Mods/` (если её нет, создайте её вручную). Внутри создайте папку для вашего мода, например:

```text
Mods/BoxSpawner/
```

---

## Шаг 2. Создание манифеста info.json

Создайте внутри папки `Mods/BoxSpawner/` файл с именем `info.json` и добавьте следующий текст:

```json
{
  "id": "box_spawner",
  "version": "1.0.0",
  "name": "Box Spawner",
  "author": "Modder",
  "description": "Спавнит ящики по нажатию клавиши H в точке курсора",
  "dependencies": []
}
```

> **Важно:** Поле `"id"` должно быть уникальным идентификатором, состоящим из строчных латинских букв, цифр и знака подчеркивания.

---

## Шаг 3. Написание логики в main.lua

Создайте в этой же папке файл `main.lua` со следующим содержимым:

```lua
function OnInit()
    Log("BoxSpawner успешно инициализирован! Нажмите H для спавна ящика.")
end

function OnUpdate(dt)
    if Input.get_key_down("H") then
        local mouse = Input.get_mouse_position()
        local world_pos = Camera.screen_to_world(mouse.x, mouse.y)
        
        local crate = World.spawn_crate(world_pos.x, world_pos.y)
        Log("Ящик создан в координатах: X=" .. string.format("%.2f", world_pos.x) .. ", Y=" .. string.format("%.2f", world_pos.y))
    end
end
```

---

## Шаг 4. Проверка в игре

1. Запустите игру.
2. В главном меню нажмите кнопку **mods**.
3. В списке модов появится **Box Spawner [ON]**.
4. Нажмите кнопку **play** для перехода на физическую арену.
5. Наведите курсор мыши в любое место экрана и нажмите клавишу `H`. В точке курсора появится полноценный физический ящик, подчиняющийся гравитации и коллизиям движка.
